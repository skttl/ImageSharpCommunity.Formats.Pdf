# Changelog

## 4.0.0

- Upgrades to ImageSharp 4.1.3 on .NET 8. The package major version now follows ImageSharp.
- Adapts PDF image identification to the ImageSharp 4 ImageInfo constructor.
- Includes an assembly-scoped Six Labors Community license, valid until 2028-02-10.
- Updates the sample apps for ImageSharp 4 and corrects their project references and decoder configuration.
- Updates CI and fixes NuGet package paths for Linux release runners.
